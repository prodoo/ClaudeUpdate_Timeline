Codex CLI Reference · Essentials

Codex CLI 핵심 명령어 기능별 대표 명령어 한 장 요약

Codex CLI에서 가장 자주 쓰는 슬래시 명령어 · 서브커맨드 · 플래그를 기능별로 묶은 핵심판. 공개 명령어 전수와 experimental 항목은 〈전체판〉에서 다룬다.
A 세션 조종Steer the session
/model활성 모델·추론 강도 전환
/fastFast 모드 켜기·끄기·상태 (on|off|status)
/planplan 모드 진입 — 인라인 프롬프트 가능
/permissions승인 프리셋 전환 (Auto·Read Only 등)
/status모델·정책·쓰기 루트·토큰 사용량 요약
/personality응답 커뮤니케이션 스타일 변경
B 컨텍스트·스레드Context & threads
/new같은 세션 안에서 새 대화 (화면 유지)
/clear터미널 화면+대화 함께 리셋
/compact이전 대화를 요약해 컨텍스트 확보
/resume저장된 세션 transcript 복원
/fork현재 대화를 새 ID 스레드로 분기
C 검토·파일Review & files
/review작업 트리를 리뷰해 이슈 요약
/diffGit diff 보기 — 미추적 파일 포함
/copy최근 완료 출력 클립보드 복사 (Ctrl+O)
/init현재 디렉터리에 AGENTS.md 생성
/mention대화에 특정 파일 첨부
D 핵심 서브커맨드Core subcommands
codex대화형 TUI 세션 시작
codex exec비대화형 1회 실행 — 별칭 codex e, stdout/JSONL 스트리밍
codex resume이전 세션 이어가기 — --last·--all
codex review작업 트리 리뷰 (비대화형)
codex mcpMCP 서버 목록·추가·인증
codex cloudCloud 작업 탐색·실행 — 별칭 cloud-tasks
E 자주 쓰는 플래그Common flags
-s, --sandbox샌드박스 모드 — read-only·workspace-write·danger-full-access
-a, --ask-for-approval승인 정책 — untrusted·on-request·never
-p, --profileconfig.toml의 권한·설정 프로파일 로드
--cd에이전트 작업 디렉터리 지정
--search라이브 웹 검색 활성화 (기본은 cached)
-c key=valueconfig 값 1회 오버라이드
핵심판
기능별 대표 명령어만 추린 한 장 요약. 공개 슬래시 명령어·codex 서브커맨드 전수와 /goal 등 experimental 항목, CLI 플래그 전수는 〈전체판〉에서 다룬다.
