버전 의존 · 공식 슬래시 문서 미수록

3자 자료·체인지로그 기반으로 존재가 보고됐으나, 현재 공식 슬래시 명령어 문서에는 등재돼 있지 않다. 사용 전 codex --version과 공식 docs로 확인할 것.
/vimTUI 컴포저 모달 Vim 편집 — 3자 자료(치트시트) 기반, 공식 docs 미확인
/hooksTUI 훅 브라우저 (활성 훅 조회·토글) — 3자 자료상 v0.129 추가 보고, 공식 슬래시 문서 미수록
전체판
공개 슬래시 명령어 + codex 서브커맨드 전수, experimental 라벨 분리. 명령어를 "언제·왜·어떻게" 쓰는지는 플레이북 5편 — 환경 세팅 · 작업 완주 · 자동화 · 멀티스레드 · 권한 심화 — 에서 다룬다.
2026년 5월 14일 기준 · v0.130.x 계열
Codex CLI는 거의 매일 패치된다. 슬래시 명령어·플래그·동작은 버전에 따라 달라질 수 있으니 codex --version과 공식 docs로 확인할 것.
