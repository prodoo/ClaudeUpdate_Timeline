/agents Specialist workers

전문 작업자를 정의해 본류 컨텍스트를 지킨다

서브에이전트는 한 세션 안에서 스폰되는 격리된 작업자다. 자체 컨텍스트 윈도우·프롬프트·도구 권한을 갖고 하나의 좁은 작업만 수행한 뒤 결과를 반환한다. 탐색·구현을 본류 대화 밖으로 빼내 메인 세션을 가볍게 유지한다.

정의 위치
.claude/agents/<name>.md(프로젝트) / ~/.claude/agents/(유저); frontmatter에 name·description·tools·model
핵심 요령
description을 "이럴 때 써라 / 이런 형태로 반환한다"로 명확히 — Claude가 위임 판단에 그대로 사용
기본 제공
빌트인 Explore(읽기 전용 탐색)·Plan(플랜 모드 리서치)·general-purpose
실전 예시
# .claude/agents/reviewer.md — tools: Read, Grep (Edit·Write 제외한 읽기 전용 리뷰어)
subagent vs team Pick the layer

보고형이냐, 협업형이냐를 먼저 구분한다

둘 다 병렬화지만 층위가 다르다. 서브에이전트는 한 세션 안의 작업자로 결과를 본류에 보고만 하고 서로 메시지를 못 한다. Agent Teams는 여러 세션을 팀 리드가 조율하고 팀원끼리 직접 소통한다.

서브에이전트
수직 병렬 — 한 세션 내부 작업자. 빠르고 좁은 위임, 결과만 회수
Agent Teams
수평 협업 — 실험적(CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1). 팀원이 공유 태스크 리스트로 조율·소통
판단 기준
작업자끼리 소통이 필요한가? 아니면 서브에이전트, 맞으면 Agent Teams. 둘은 조합 가능
실전 예시
"인증 시스템 리뷰 팀 구성 — 보안 / 성능 / 테스트 커버리지 팀원 3명, 태스크 리스트로 공유·조율해"
parallel subagents Fan-out explore

한 번에 여러 갈래로 코드베이스를 훑는다

한 세션이 서브에이전트 여러 개를 동시에 스폰하면 각자 독립 컨텍스트로 병렬 실행되고, 모두 끝나면 본류 세션이 결과를 모아 재개한다. 탐색·heavy-context 작업에 특히 강하다.

사용 시점
코드베이스를 여러 관점으로 동시 탐색, 본류를 오염시킬 무거운 컨텍스트 작업
트레이드오프
토큰 비용 ↑ vs 벽시계 시간 ↓ — 토큰이 빠듯하면 순차, 시간이 빠듯하면 병렬
간단 대안
조율이 필요 없는 독립 변경은 /batch — worktree 격리를 자동 처리
실전 예시
"동시에 찾아줘 — ① Database.connect 호출처 ② 커넥션 풀 설정 ③ 에러 처리. 셋 다 끝나면 돌아와"
--worktree Write isolation

에이전트들이 서로의 파일을 밟지 않게 한다

여러 에이전트가 같은 repo를 건드릴 때 충돌을 막는 장치. 백그라운드 세션은 처음 파일을 쓰는 순간 .claude/worktrees/ 아래 격리된 워크트리로 자동 이동한다 — 읽기는 공유, 쓰기는 분리.

진입 방법
-w / --worktree 플래그, 서브에이전트·포크는 isolation: worktree
분기 기준
worktree.baseRef 설정 (fresh=원격 기본 브랜치 / head=로컬 HEAD)
주의
병렬 작업의 진짜 병목은 머지 충돌 — 브랜치·워크트리 규율 없이는 처리량 이득이 사라진다
실전 예시
claude -w "결제 모듈 리팩터링" — 격리된 워크트리·브랜치에서 작업
claude agents Command center

모든 세션을 한 화면에서 지휘한다

모든 백그라운드 세션을 하나의 CLI 대시보드에 모아 실행·대기·완료 상태를 보여준다. tmux 패널을 일일이 들여다보던 수동 오케스트레이션을 단일 화면으로 대체한다.

요구 사항
v2.1.139+, Research Preview(2026.05.11). Free 플랜 제외 — Pro/Max/Team/Enterprise/API
핵심 가치
어느 에이전트가 내 입력을 기다리는지 즉시 파악, 컨텍스트 잃지 않고 답장·attach
지속성
슈퍼바이저 프로세스가 상태를 디스크에 저장(roster.json) — 재부팅해도 세션 복원
실전 예시
claude agents → 입력창에 작업 프롬프트 → Enter 로 새 세션 디스패치
/goal Autonomy & cost

자율 실행에 완료 조건과 예산을 건다

/goal은 완료 조건을 걸면 충족될 때까지 여러 턴에 걸쳐 자율 작업하고, 경과 시간·턴·토큰을 오버레이로 보여준다. 자율성이 커질수록 비용 통제가 짝을 이뤄야 한다. 한 대화로 조율하기 벅찬 대규모 작업은 /workflows로 오케스트레이션 스크립트화해 백그라운드에서 많은 서브에이전트로 돌린다(연구 미리보기).

비용 현실
세션·팀원마다 쿼터를 독립 소모 — 팀원 3명 ≈ 3~4배 토큰, 병렬 세션 5개 ≈ 한도 5배
통제
단순 작업은 Sonnet·깊은 추론만 Opus / --max-turns·--max-budget-usd로 상한
주의
Pro의 5시간 롤링 한도 — 큰 에이전트 팀을 띄우기 전 플랜 한도부터 확인
실전 예시
/goal 결제 테스트가 통과할 때까지 진행하고, 통과하면 멈춰
