A

실행 및 세션 관리 명령어

claude
터미널에서 Claude Code를 실행하는 기본 명령어
/clear
현재 세션 대화 내역을 삭제해 컨텍스트를 비움 (파일 수정 결과는 유지)
claude -c
직전에 진행하던 대화를 컨텍스트 그대로 이어서 재개
/compact
긴 대화를 핵심 맥락만 남겨 압축; /compact 인증 결정만 유지처럼 보존 지시 권장
claude -r "이름"
이름·제목으로 지정한 과거 세션을 복구해서 다시 시작
/context
컨텍스트 윈도우 사용량을 스킬·항목별로 확인 (압축 시점 판단용)
/resume
과거 세션 목록을 열어 재개; Ctrl+A로 전체 프로젝트 표시
Ctrl+C
생성 중단; 프롬프트가 비어 있을 때 두 번 누르면 세션 종료
B

상태 및 권한 설정 명령어

/permissions
파일 접근·실행 권한 모드 및 최근 거부 내역 관리
/status
현재 모델, 권한 모드, 연결된 MCP 서버 등 세션 상태 확인
/doctor
환경 진단 실행; f 키를 누르면 발견된 문제를 자동 수정
/model
사용 모델 전환 (opus / sonnet / haiku / opusplan)
/effort
추론 강도 조절 (low~max); xhigh는 Opus 4.7+ 전용, 인자 없이 실행 시 슬라이더
/init
프로젝트 지침 파일 CLAUDE.md 생성 — 가장 중요한 설정 명령어
/memory
CLAUDE.md 등 메모리 파일 열기·편집
C

작업 제어 및 모드 전환 명령어

/plan
바로 코딩하지 않고 계획부터 수립하는 플랜 모드로 전환
Shift+Tab
권한 모드 순환: default → acceptEdits → auto → plan
/review
현재 브랜치의 코드 변경 사항을 리뷰
/security-review
변경된 코드 대상 보안 취약점 중심 리뷰; 병합·릴리스 전 권장
/goal
완료 조건을 설정하면 충족될 때까지 여러 턴에 걸쳐 작업 지속
/fast
패스트 모드 토글; 빠른 반복 작업에 유용
!
채팅창 내 Bash 모드로 전환해 !ls 같은 셸 명령어 즉시 실행
/agents
서브에이전트 생성·관리; claude agents로 에이전트 뷰 확인
D

프롬프트 및 UI 단축키

Esc Esc
리와인드 메뉴 열기 — 코드·대화를 이전 체크포인트로 되돌림 (/rewind)
Ctrl+R
프롬프트 히스토리 역방향 검색; Ctrl+S로 검색 범위 전환
↑ / ↓
이전에 작성했던 프롬프트 히스토리 탐색
Ctrl+G
외부 텍스트 에디터를 열어 긴 프롬프트를 편하게 작성
\ + Enter
전송 없이 줄바꿈해 멀티라인 입력 (Shift+Enter / Ctrl+J 도 동일)
Ctrl+T
작업(Task) 목록 보기 토글; 최대 5개까지 표시
Ctrl+O
일반 / 상세(verbose) 트랜스크립트 뷰 전환
@파일명
파일·디렉터리·URL을 컨텍스트로 멘션 (붙여넣기보다 토큰 처리에 유리)
CI

Claude Code 클라우드 및 GitHub 연동

자동 GitHub 코드 리뷰

/install-github-app으로 GitHub App을 연동하면 PR이 열릴 때마다 GitHub Actions 기반으로 Claude가 코드 검토와 코멘트를 자동 수행함.

클라우드 및 원격 제어

/remote-control(별칭 /rc)로 클라우드 세션 연결, /schedule로 예약 작업 실행, /teleport로 기기 간 세션 전환.

/mcp
MCP 서버 관리; 연결 후 /mcp__[서버]__[프롬프트] 형식 명령 자동 생성
/ultrareview
병렬 멀티 에이전트 기반 클라우드 종합 코드 리뷰 (PR 번호 지정 가능)
