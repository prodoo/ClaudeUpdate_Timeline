context rot The principle

컨텍스트는 용량이 아니라 큐레이션의 문제다

컨텍스트 윈도우는 모델의 작업 기억이다. 토큰이 차오를수록 정확도와 회상이 떨어진다 — 컨텍스트 로트(context rot). 1M 토큰이 들어가도, 무엇을 넣느냐가 얼마나 넣느냐보다 중요하다.

핵심 명제
더 많이 ≠ 더 좋음 — 채우는 게 아니라 큐레이션하는 것
1차 제약
컨텍스트는 세션의 1차 제약 — 속도·비용·품질이 모두 여기 묶인다
출발점
무엇이 자리를 차지하는지부터 파악한다 (다음 카드)
실전 예시
# 무관한 파일 10개를 읽힌 세션 vs @-멘션으로 필요한 3개만 — 후자가 더 정확
/context What fills it

무엇이 컨텍스트를 채우는지 먼저 본다

입력하기도 전에 CLAUDE.md·auto memory·MCP 도구 이름·스킬 설명·시스템 프롬프트가 이미 로드된다. 작업이 진행되면 파일 읽기·도구 결과·명령 출력이 계속 쌓인다.

시작 시
CLAUDE.md 계층, auto memory, MCP 도구 이름, 스킬 설명, output style
누적분
매 파일 읽기·도구 결과·서브에이전트 요약 — 턴이 갈수록 증가
점검
/context로 카테고리별 실시간 사용량과 최적화 제안 확인
실전 예시
붙여넣기 대신 @README.md·@src/ — 토큰 처리가 더 효율적
CLAUDE.md Hierarchy

CLAUDE.md 계층으로 지시문을 층층이 쌓는다

Claude Code는 작업 디렉터리에서 루트까지 거슬러 올라가며 CLAUDE.md를 모은다. 나중에 로드된 파일이 더 큰 가중치를 받는다 — CWD에 가까울수록 우선순위가 높다.

4계층
관리자(/etc/claude-code/) → 유저(~/.claude/CLAUDE.md) → 프로젝트(CLAUDE.md) → 로컬(CLAUDE.local.md, gitignore)
디버깅
규칙이 안 먹으면 /memory로 어떤 파일이 어떤 순서로 로드됐는지 확인
주의
@import는 내용을 인라인 확장 — 정리엔 좋지만 컨텍스트를 절약하진 않음
실전 예시
# 루트 CLAUDE.md는 80줄 이하 + 패키지별 30~60줄 — 가벼운 시작 유지
.claude/rules/ Scoped loading

거대한 CLAUDE.md를 규칙 단위로 쪼갠다

모든 걸 한 CLAUDE.md에 넣으면 무관한 지시까지 매번 높은 우선순위로 경쟁한다. .claude/rules/로 쪼개면 path-scoped 규칙은 매칭되는 파일을 읽을 때만 로드된다.

path-scoped
paths: frontmatter로 특정 경로 작업 시에만 활성 (브레이스 확장 src/**/*.{ts,tsx})
중첩 파일
하위 디렉터리의 CLAUDE.md는 시작 시 로드 안 됨 — 그 폴더 파일을 읽을 때 로드
효과
시작 컨텍스트는 가볍게, 지역 지시는 필요할 때만
실전 예시
packages/auth/CLAUDE.md — auth 폴더 작업을 시작할 때만 로드
subagent + /btw Isolate the main

본류 컨텍스트를 격리로 지킨다

무거운 작업은 본류 밖으로 뺀다. 서브에이전트는 별도 컨텍스트 윈도우에서 리서치를 처리하고 — 큰 파일 읽기는 거기 머물고 요약과 짧은 메타데이터만 돌아온다.

서브에이전트
별도 윈도우, 탐색·구현을 본류에서 분리 (전체 메모리 계층 대신 집중 컨텍스트)
/btw
서브에이전트의 정반대 — 전체 대화는 보지만 도구는 없음, 부모 프롬프트 캐시 재사용으로 거의 무비용
판단
새로 찾아야 하면 서브에이전트, 이미 아는 걸 물으면 /btw
실전 예시
/btw 진행 중인 작업을 멈추지 않고 빠른 확인 질문
/compact Survive compaction

압축 이후에 무엇이 살아남는지 안다

/compact는 대화를 구조화된 요약으로 대체한다. 지시문 파일은 처음부터 다시 읽히므로 CLAUDE.md 규칙은 살아남지만, 일부는 요약과 함께 사라진다.

살아남음
루트 CLAUDE.md, auto memory — 압축 후 자동 재로드
사라짐
path-scoped 규칙·중첩 CLAUDE.md는 요약돼 날아감 (다음 매칭 파일 읽을 때 재로드)
스킬 절단
스킬 본문은 재주입되나 per-skill 상한으로 잘림 — 중요한 지시는 SKILL.md 맨 위에
실전 예시
/compact 컨텍스트 70~75%에서 보존 지시와 함께 (경고 전에 미리)
