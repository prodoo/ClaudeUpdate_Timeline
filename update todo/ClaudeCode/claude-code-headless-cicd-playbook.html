claude -p Headless basics

터미널 없이 단발 프롬프트를 실행한다

-p(--print)를 붙이면 Claude Code가 대화형 인터페이스 없이 전체 에이전트 루프(사고·도구 호출·편집)를 돌리고 즉시 종료한다. stdin을 읽고 stdout으로 내보내는 — 평범한 CLI 도구가 된다.

기본형
claude -p "테스트 실행하고 실패한 것 고쳐" — 한 명령으로 끝
파이프
cat build-error.txt | claude -p "근본 원인 설명" > out.txt
위치
모든 CI/CD 통합의 토대 — GitHub Actions·GitLab CI·Jenkins·셸 스크립트
실전 예시
cat error.log | claude -p "이 에러 진단해"
--bare Deterministic

--bare로 어느 머신에서나 같은 결과를 낸다

기본 claude -p는 인터랙티브 세션과 똑같이 작업 디렉터리와 ~/.claude의 설정을 모두 읽는다. --bare는 hooks·skills·plugins·MCP·auto memory·CLAUDE.md 자동 탐색을 건너뛴다.

효과
명시한 플래그만 적용 — 팀원의 훅이나 프로젝트 .mcp.json이 끼어들지 않음
권장
CI·스크립트·SDK 호출의 권장 모드 — 향후 -p의 기본값이 될 예정
범위
Bash·파일 읽기·편집 도구는 사용 가능, OAuth·키체인 읽기는 건너뜀
실전 예시
claude --bare -p "이 파일 요약" --allowedTools "Read"
--output-format Parse the result

출력 포맷으로 결과를 받아 멀티턴으로 잇는다

헤드리스는 세 가지 출력 포맷을 지원한다. 사람이 읽을 땐 text, 스크립트로 파싱할 땐 json, 실시간 처리엔 stream-json. json에서 받은 session_id로 여러 호출을 한 맥락으로 묶는다.

3종
text(기본·raw) / json(result·session_id·cost 등 구조화) / stream-json(NDJSON, 이벤트별)
파싱
claude -p "..." --output-format json | jq -r '.result'
멀티턴
json의 session_id를 --resume로 재사용 — 독립 호출보다 토큰 절약
실전 예시
SESSION=$(claude -p "분석" --output-format json | jq -r '.session_id')
--allowedTools Attack surface

도구를 제한해 공격 표면을 좁힌다

헤드리스에선 권한 프롬프트를 승인할 사람이 없다. --allowedTools로 Claude가 쓸 수 있는 도구를 명시적으로 제한해 공격 표면을 최소화한다.

읽기 전용
--allowedTools "Read,Grep,Glob" — 분석·리뷰용
쓰기 허용
Read,Write,Edit — 수정 작업용
주의
--dangerously-skip-permissions는 격리된 CI 컨테이너에서만. --permission-mode plan이라도 Claude는 저장소를 봄 — 평문 비밀이 있는 repo는 CI에 올리지 말 것
실전 예시
claude -p "버그 찾아" --allowedTools "Read,Grep,Glob"
--max-turns No human brake

사람이 없는 만큼 비용을 미리 묶는다

비용은 CI 통합의 조용한 킬러다. 새벽 3시에 40개 PR에 걸쳐 안 보이게 돌아간다 — 사람이 브레이크를 밟을 수 없다. 상한을 코드로 박아야 한다.

--max-turns
한 호출의 에이전트 반복 횟수 제한 — CI에선 항상 추가
모니터링
json 출력의 total_cost_usd·모델별 분해로 호출당 비용 추적
정책 변경
2026.6.15부터 구독 플랜의 claude -p·Agent SDK 사용량은 인터랙티브와 별도인 월간 Agent SDK 크레딧에서 차감
실전 예시
리뷰는 --max-turns 5, 단순 설명은 --max-turns 1
claude-code-action Repo integration

GitHub Actions로 저장소 이벤트에 엮는다

공식 anthropics/claude-code-action을 쓰면 PR·이슈 코멘트에서 @claude 멘션으로 코드 구현·PR 생성을 시킬 수 있다. 커스텀이 필요하면 YAML에서 claude -p를 직접 호출한다.

설정
ANTHROPIC_API_KEY를 repo Secret으로, /install-github-app으로 GitHub App 연동
CLAUDE.md
리뷰 기준·코드 규칙·"main에 직접 푸시 금지"를 한 번 적어두면 매 실행에 적용 — CI 설정 역할
트리거 구분
repo 이벤트(PR·push)면 Actions, 시간 기반이면 /schedule
실전 예시
PR 코멘트에 @claude → 코드 검토 후 코멘트·커밋
