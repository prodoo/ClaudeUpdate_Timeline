4 mechanisms Orientation

네 가지 확장 메커니즘을 먼저 구분한다

Claude 생태계엔 헷갈리기 쉬운 네 가지 확장 수단이 있다. 비유하자면 MCP는 부엌(칼·냄비·재료=도구), 스킬은 레시피(그 도구를 어떻게 쓸지)다 — 둘은 서로 결합된다.

Skills
작업 방법을 알려주는 지시문 — 가장 가볍고 이식성이 높음(Codex·Cursor 등 공통)
MCP
외부 도구·데이터 소스를 표준 프로토콜로 노출하는 실행 프로세스
Subagent / Plugin
격리된 작업자 / 위 모두를 묶는 배포 단위
실전 예시
# Sentry 코드 리뷰 스킬 = PR 분석 워크플로는 SKILL.md, 에러 데이터는 MCP
SKILL.md Build a skill

SKILL.md 하나로 스킬을 만든다

스킬은 SKILL.md 파일을 담은 폴더다 — YAML frontmatter(name·description)와 마크다운 지시문, 선택적 스크립트·리소스. Claude가 작업 맥락에 맞춰 자동 호출하고, 안 쓰일 땐 컨텍스트를 안 차지하게 점진 로딩된다.

위치
.claude/skills/<name>/(프로젝트) / ~/.claude/skills/<name>/(유저)
두 종류
Capability Uplift(없던 능력 부여, 실행 스크립트 포함) vs Encoded Preference(우리 팀 방식을 박제)
제작
반복 설명하는 워크플로가 보이면 그때 — Skill Creator의 인터랙티브 Q&A로 골격 생성
실전 예시
description을 명확히 — Claude가 "언제 이 스킬을 쓸지" 판단하는 근거
/skills Invoke

이름 멘션·슬래시·자율 호출로 불러온다

스킬은 세 가지 방식으로 발동한다. 이름을 멘션하거나("PDF 스킬 써서…"), /name 슬래시로 직접 부르거나, Claude가 맥락을 보고 자율적으로 호출한다.

명령 통합
커스텀 슬래시 명령이 스킬로 통합됨(v2.1.101) — .claude/commands/는 레거시, .claude/skills/<name>/SKILL.md 권장
인자
$ARGUMENTS·$1·$2로 명령 뒤 텍스트를 받음
frontmatter
allowed-tools·model·argument-hint·effort로 동작 제어
실전 예시
/skills — 설치된 스킬 목록 확인 (타입 입력 필터 검색 지원)
/plugin Distribution

Plugins로 묶어서 배포한다

플러그인은 배포 포맷이다. 스킬·서브에이전트·훅·MCP 서버·슬래시 명령을 하나의 설치 단위로 묶는다 — "플러그인은 배포 포맷, 스킬은 내용물."

구조
.claude-plugin/plugin.json 매니페스트 + skills/·agents/·hooks/·.mcp.json
설치
/plugin marketplace add <github-repo> → /plugin install <name>@<marketplace>
출처
공식 Anthropic 마켓플레이스(검증됨) vs 커뮤니티 GitHub repo(품질 편차 큼)
실전 예시
/plugin marketplace add — 팀 전용 마켓플레이스 등록 후 일괄 설치
/mcp Connect tools

MCP로 외부 도구를 연결한다

MCP 서버는 표준 프로토콜로 도구와 데이터 소스를 Claude에 노출한다. 연결하면 각 서버의 프롬프트가 동적 슬래시 명령으로 나타난다.

관리
/mcp로 서버 연결·관리; .mcp.json 편집은 재연결로 반영
동적 명령
연결 후 /mcp__server__prompt 형식 명령이 자동 생성 (예: /mcp__github__list_prs)
스킬과 결합
MCP=도구, 스킬=사용법 — SKILL.md가 MCP 도구 사용 워크플로를 정의
실전 예시
GitHub MCP 연결 → /mcp__github__create_pr 로 PR 생성
extension safety Arbitrary code

임의 코드 실행을 전제로 검토 후 설치한다

스킬·플러그인은 Claude 환경에서 임의 코드를 실행할 수 있다. 특히 훅·MCP 서버를 포함한 플러그인은 내 머신에서 코드를 돌린다 — 커뮤니티 마켓플레이스는 공식만큼 검수되지 않는다.

검토 습관
신뢰 못 할 출처는 SKILL.md와 scripts/ 폴더를 직접 읽을 것 — Bash 명령·네트워크 요청 주의
안전 테스트
--plugin-dir로 로컬 복사본 우선 로드, --plugin-url은 해당 세션만; /reload-plugins로 재시작 없이 갱신
출처 확인
공식 플러그인은 검증됨, 커뮤니티는 제작자 프로필·저장소 활동을 확인
실전 예시
# 설치 전 — 훅·MCP 서버 포함 여부와 plugin.json을 먼저 확인
