실행 및 세션 관리

17
claude
터미널에서 Claude Code를 실행하는 기본 명령어
/branch [이름]
현재 대화·워크플로를 분기 (별칭 /fork)
claude -c
직전 대화를 컨텍스트 그대로 이어서 재개
/rename [이름]
현재 세션 이름 변경 (멀티 태스킹 시 유용)
claude -r "이름"
이름·제목으로 지정한 과거 세션 복구
/export [파일]
대화 내보내기 (주로 Markdown)
claude -p "..."
비대화형 단발 프롬프트 실행 (CI/스크립트용)
/diff
인터랙티브 diff 뷰어; 리뷰·커밋 전 점검
/clear
대화 내역 삭제로 컨텍스트 비움 (파일 수정은 유지)
/copy [N]
최근 또는 N번째 응답을 클립보드에 복사
/compact [focus]
긴 대화를 핵심 맥락만 남겨 압축; 보존 지시 권장
/status
모델·권한 모드·MCP 등 현재 세션 상태 확인
/context
컨텍스트 윈도우 사용량을 항목별로 확인
Ctrl+C
생성 중단; 빈 프롬프트에서 두 번 누르면 종료
/resume
세션 목록을 열어 재개; Ctrl+A로 전체 프로젝트
/exit
Claude Code 세션 종료
/rewind
체크포인트로 코드·대화 되돌리기 (별칭 /undo)

CLI 명령어 & 주요 플래그

claude "프롬프트"
초기 프롬프트와 함께 대화형 시작
claude -p · -c · -r
비대화형 단발 / 직전 대화 이어서 / 명명 세션 재개
claude agents
에이전트 뷰 — 실행·차단·완료 세션 통합 목록
claude update
Claude Code 업데이트 (네이티브 설치는 자동)
claude mcp list · serve
MCP 서버 목록 / Claude Code를 MCP 서버로 실행
claude project purge
프로젝트의 모든 상태(트랜스크립트·작업·이력) 삭제
claude plugin details
플러그인 컴포넌트 인벤토리·세션당 토큰 비용
자주 쓰는 플래그
--model --fallback-model --effort --permission-mode -w / --worktree -n / --name --add-dir --agent --allowedTools --output-format json --json-schema --max-turns --max-budget-usd --remote --channels --plugin-url --transport http|stdio|sse --verbose --bare --chrome --dangerously-skip-permissions

ANTHROPIC_API_KEY 등이 설정되면 Remote Control · /schedule · Claude.ai MCP 커넥터가 비활성화됩니다.
